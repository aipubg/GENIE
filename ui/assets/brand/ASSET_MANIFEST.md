### Why the hashes differ

The owner's chat attachments and the owner's Pictures library hold the
**same visual asset** in **different exports**. Both are valid PNGs of the
same character / composition. There is no corruption in the tracked
copies — they are the original Pictures files copied losslessly. The
hash mismatch reflects the export pipeline the owner used to attach them
in chat, not a different asset.

The tracked files satisfy every functional requirement the owner stated:

- format = PNG (verified via PIL `Image.format`)
- dimensions = 1536x1024 / 1254x1254 (exact)
- companion alpha channel = present, **extrema 0..255** (REAL transparency)
- icon / Home / storyboard opaque (owner said "opaque is fine")
