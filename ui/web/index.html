GENIE backend

This HTTP port is the backend's diagnostic surface. It is not a desktop UI. The owner-facing application is Genie.Desktop, the Windows-native client, which talks to this same backend over these same endpoints.

Operations dashboard Control centre Health endpoint
The browser-based desktop UI that used to live here was removed once the native client reached parity: two owner-facing shells means two places for the same truth to drift. These diagnostic pages remain because they are genuinely useful for support and debugging, and they read the same authoritative endpoints the native client reads.
